# 🏛️ Louvre Tour Guide

A mobile-friendly Progressive Web App to navigate the Louvre museum. Select your room number to discover nearby masterpieces with images and brief historical context.

## Features
- 📍 Room-based navigation — no GPS needed, just match your room number
- 🖼️ 25+ curated masterpieces across all 3 wings
- 📱 Installable PWA — works offline after first visit
- 🚀 Quick-jump to famous spots (Mona Lisa, Venus de Milo, Winged Victory)
- 🕰️ Fascinating historical context for each artwork

## Usage
1. Open on your phone: `davohill88.github.io/louvre-tour/`
2. Select which wing you're in (Denon, Sully, or Richelieu)
3. Select your floor
4. Enter your room number (posted on signage)
5. See nearby masterpieces with images and history

## Data Sources
All artwork data from Wikipedia. Images from Wikimedia Commons. Not affiliated with the Musée du Louvre.
